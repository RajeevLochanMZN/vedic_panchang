Portrait dial page for Pi 2 (480 x 800)  --  copy the 5 files into your project's ui/ folder

NEW      ui/page_vedic_dial_portrait.py      portrait layout (corner clock/date, 6-row panels) + PC preview
NEW      ui/page_vedic_dial_portrait_hi.py   live page = PageVedicDialHi + that layout
CHANGED  ui/dial_vedic.py      ring size/margin now settable (landscape values unchanged);
                               tags are kept inside the widget sideways (fixes the clipped Abhijit tag)
CHANGED  ui/info_panels.py     text-size settings added to InfoPanel (defaults = old landscape values)
CHANGED  ui/main_window_hi.py  uses the portrait page when the screen is taller than wide

Also in this zip (for Pi 2): ui/rotated_host.py (the clock turns its own picture), tools/set_display.sh
(app-rotate), tools/apply_display_mode.sh, tools/screen_test.py.  See PI2_SETUP.txt for the steps.

Pi 1 (landscape) keeps PageVedicDialHi, nothing visible changes there.
page_vedic_dial_hi.py and page_vedic_dial.py are NOT changed.

Test on the PC (venv active):
  python ui/page_vedic_dial_portrait.py        sample data, 480x800 window
  python ui/page_vedic_dial_portrait.py empty  swastik cards
  python ui/page_vedic_dial_portrait_hi.py     live engine, 480x800 window

Deploy: git add . / commit / push on the PC; on the Pi git pull, then (Pi 2 only)
rotate the screen BEFORE the clock starts (wlr-randr --output <name> --transform 90 or 270).

IMPORTANT: copy ALL FIVE files together.  The portrait page only sets sizes; the
code that draws them lives in info_panels.py and dial_vedic.py.  With an old copy
of either one the sizes silently stay at the old values.  The page now prints a
"*** PORTRAIT PAGE: OLD FILE IN USE" warning in the console when that happens.

Check what is really in use:   python ui/page_vedic_dial_portrait.py --check
(prints the window size, scale factor and the pixel size of every text line).
The test window must really be 480 x 800: on a screen shorter than ~860 px
Windows shrinks it, and the whole page (text included) shrinks with it.
