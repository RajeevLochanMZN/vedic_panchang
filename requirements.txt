pyswisseph

step1 
Update package lists
sudo apt update && sudo apt upgrade -y

step 2 
Install system packages
sudo apt install -y python3-pyqt5 python3-venv python3-pip i2c-tools python3-smbus build-essential python3-dev

step 3 
Create the virtual environment
cd ~/VedicGhadi
python3 -m venv venv --system-site-packages
source venv/bin/activate

Your prompt should change to show (venv) at the front once activated. Then:

pip install pyswisseph gpiozero PyYAML
varify with 
python3 -c "import PyQt5, swisseph, yaml, gpiozero; print('all imports OK')"
